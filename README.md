# Data_Visualisation_Lab

# List of Experiments

## Part- A

### 1. Using Python, preprocess a high-dimensional housing dataset with continuous, discrete, ordinal, and nominal variables by handling missing values, duplicates, and outliers.

Apply Min-Max normalization and Z-score standardization, and generate bar plots and box plots. Generate histograms and scatter plots before and after normalization to compare the changes in data distribution, scale, and relationships.

### 2. Using Python, perform exploratory analysis of a multivariate dataset

Create bar, stacked bar, line, scatter, bubble, histogram, box plot, heatmap, radar, pie, tree map, and word cloud visualizations. Examine the visualizations to identify distributions, outliers, trends, correlations, and patterns. Interpret the results to identify important insights from the dataset.

### 3. Obtain time-series stock-market data and perform analysis using Python

Generate candlestick charts, SMA and EMA overlays, rolling volatility bands, and volume trend plots. Examine the data to identify trends, seasonal patterns, and significant changes over time. Evaluate the visualizations to determine relationships among key variables, variability, and long-term trends.

### 4. Employ a suitable high-dimensional dataset

Create parallel coordinates plots and scatterplot matrices for examining relationships among multiple features. Perform PCA to reduce the data to 2D and 3D, and generate scree plots and cumulative explained variance plots. Develop class-colored 2D and 3D PCA visualizations to identify patterns, clusters, and underlying structures in the dataset.

### 5. Select a suitable census dataset

Perform exploratory spatial and demographic analysis by handling missing values and normalizing numerical fields. Create demographic charts, distribution plots, treemaps, and interactive geospatial maps to visualize patterns, relationships, and regional variations, and examine the visualizations to identify demographic trends, disparities, and underlying structural patterns.

### 6. Choose an appropriate multi-variable dataset

Generate interactive Python visualizations using Plotly to analyze feature patterns and relationships. Add dynamic text and shape annotations to highlight key observations, such as peaks, troughs, clusters, outliers, trends, min/max values, and threshold crossings. Interactively inspect the annotated charts to identify critical data behaviors and extract meaningful analytical insights.

### 7. Develop an interactive retail analytics dashboard using Plotly Dash

Create KPI indicators and dynamic filters. Create line, stacked bar, treemap, scatter, and choropleth visualizations to explore sales, profitability, product, and geographical patterns. Analyze the interactive dashboard to identify key trends, relationships, variations, and business insights.

### 8. Consider a suitable transportation dataset

Represent it as a network using Graphviz, then visualize locations, routes, connectivity, and network structure using appropriate graph layouts and analyze the visualization to identify highly connected nodes, important routes, clusters, and transportation patterns.

### 9. Generate a suitable 3-D mathematical or real-world data surface

Visualize it using surface and contour plots. Incorporate hidden-surface removal and PM3D-style coloring to enhance the visualization. Analyze the visualizations to identify important patterns, variations, and surface characteristics.

### 10. Consider the 20 Newsgroups dataset

A collection of text documents from different discussion topics. Create word clouds, frequency charts, document-term visualizations, and other suitable graphical representations to explore important terms and patterns across documents, and analyze the visualizations to identify frequently occurring terms, similarities, differences, and meaningful patterns.

### 11. Create a Tableau Social Media Dashboard

Using a suitable social media marketing dataset to analyze campaign performance across different platforms.

#### a. Create visualizations for reach, engagement, clicks, conversions, website traffic, and PPC performance, along with suitable KPI indicators.

#### b. Add interactive filters to compare social media platforms, campaigns, and time periods, and combine the visualizations into an interactive dashboard.

#### c. Analyze the dashboard to identify campaign trends, engagement patterns, traffic variations, conversion performance, and key marketing insights.

### 12. Create a Tableau 360-View Account Management Dashboard

Using a suitable customer/account dataset to provide a comprehensive view of account information and business performance.

#### a. Create visualizations for account value, customer lifetime value, sales performance, organizational structure, and key account indicators.

#### b. Add interactive filters to explore individual accounts, customer segments, business units, and performance indicators, and combine the visualizations into an interactive dashboard.

#### c. Analyze the dashboard to identify account performance, customer value, organizational patterns, and important indicators that support effective account management and decision-making.
